# @simo/plugin-tab-page

> 标签页（浏览器式多标签） — 让 NocoBase 的菜单和页面像浏览器标签页一样打开、切换、关闭。

## 简介

默认情况下，NocoBase 点击菜单时是整页跳转，上一个页面的状态会丢失。本插件在页面顶部（紧贴全局导航栏下方）增加一条**浏览器风格的标签栏**：每打开一个菜单/页面就新增一个标签，点击标签即可在已打开的页面之间切换，页面状态（滚动位置、表单输入、筛选条件等）会被保留。关闭标签、达到数量上限时的行为、标签外观均可配置。禁用插件后立即恢复 NocoBase 原生的整页跳转。

插件通过覆盖 `AdminLayoutModel` 实现，未修改 NocoBase 核心代码；标签栏以 `position: fixed` 固定在顶部导航栏正下方、横跨整个视口宽度，无论当前页面是普通菜单、分组菜单（二级/三级菜单）还是设置页，标签栏始终位于最上方。

## 功能特性

- **浏览器式多标签**：打开菜单即新增标签，点击标签切换页面，页面状态通过 NocoBase 的 KeepAlive 保留。
- **始终置顶**：标签栏固定在顶部导航栏正下方，横跨整个宽度，位于侧边栏（分组菜单）和内容区之上，不会被页面内容遮挡。
- **多种关闭方式**：
  - 标签上的 × 关闭按钮（可配置始终显示 / 悬停显示 / 仅当前标签显示）
  - 鼠标中键点击关闭
  - 右键菜单批量关闭（关闭其他 / 关左侧 / 关右侧 / 关闭全部）
- **标签数量管理**：可设上限（0 = 不限制），达到上限时可选「自动关闭最久未使用的标签」或「拒绝打开新标签并提示」。
- **固定标签**：可固定（Pin）标签使其不被关闭；首页标签可设为始终固定。
- **刷新**：标签栏右侧刷新按钮可强制刷新当前页面；右键菜单可刷新指定标签。
- **外观可调**：标签大小（小/中/大）、样式（卡片/圆角/下划线）、最大/最小宽度、是否显示菜单图标。
- **刷新后恢复**：可配置刷新浏览器后恢复之前打开的标签列表（基于 sessionStorage）。
- **全局配置 + 个人偏好**：管理员配置全局默认值；普通用户可在自己浏览器中部分覆盖外观与关闭行为。
- **即开即关**：禁用插件立即恢复原生整页跳转，不残留任何状态。
- **国际化**：内置简体中文 / 英文。

## 安装

本插件为源码插件，放置在 NocoBase 项目的 `packages/plugins/@simo/plugin-tab-page/` 目录下。

启用后刷新浏览器即可看到标签栏。设置页位于 **插件管理 → 标签页**（ `/v/admin/settings/tab-page`）。

## 使用说明

### 基本操作

| 操作 | 效果 |
|------|------|
| 点击左侧菜单 | 打开对应页面，并在标签栏新增一个标签 |
| 点击标签 | 切换到该标签对应的页面（保留页面状态） |
| 点击标签 × | 关闭该标签（受关闭按钮可见性设置控制） |
| 鼠标中键点击标签 | 关闭该标签（需开启「鼠标中键点击关闭」） |
| 右键点击标签 | 弹出批量操作菜单（刷新 / 关闭 / 关闭其他 / 关左侧 / 关右侧 / 关闭全部 / 固定） |
| 标签栏右侧刷新按钮 | 强制刷新当前页面 |
| 标签溢出时鼠标滚轮 | 横向滚动标签栏 |
| 标签溢出时左右箭头 | 按钮滚动标签栏 |

### 全局配置（管理员）

管理员在 **插件管理 → 标签页** 页面的「全局默认」区域配置，对所有用户生效。

#### 数量

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用标签页模式 | 总开关。关闭后标签栏隐藏，恢复原生整页跳转 | 开 |
| 标签数量上限 | 同时打开的最大标签数，填 `0` 表示不限制（上限 50） | 10 |
| 达到上限时 | `自动关闭最久未使用的标签`（LRU 淘汰）或 `不再打开新标签`（拒绝并提示用户先关闭一个） | 自动关闭最久未使用的标签 |

#### 外观

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 标签大小 | 小（高 26px）/ 中（高 32px）/ 大（高 40px） | 中 |
| 标签样式 | 卡片 / 圆角 / 下划线 | 卡片 |
| 标签最大宽度（px） | 标签超过此宽度时标题省略显示 | 180 |
| 标签最小宽度（px） | 标签最小宽度 | 90 |
| 显示菜单图标 | 标签标题前是否显示菜单图标 | 开 |
| 显示刷新按钮 | 标签栏右侧是否显示刷新当前页按钮 | 开 |

#### 关闭方式

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 关闭按钮 | `始终显示` / `悬停时显示` / `仅当前标签显示` | 悬停时显示 |
| 鼠标中键点击关闭 | 中键点击标签关闭 | 开 |
| 右键菜单 | 右键标签弹出批量关闭菜单 | 开 |
| 固定首页标签 | 第一个打开的标签不可关闭 | 开 |
| 至少保留一个标签 | 禁止关闭最后一个标签 | 开 |
| 关闭标签时销毁页面 | 关闭标签时立即销毁页面模型释放内存（下次打开重建）；关闭则仅移除标签，页面缓存自然过期 | 关 |
| 刷新后恢复标签 | 浏览器刷新后恢复之前打开的标签列表 | 开 |

#### 其他

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 允许用户覆盖以上设置 | 开启后普通用户可在自己浏览器中覆盖外观与关闭行为（见下文「个人配置」） | 开 |

> **注意**：数量上限、达到上限时的策略、标签最小宽度、固定首页标签、至少保留一个标签、关闭时销毁页面、允许用户覆盖 这几项为管理员专属，普通用户无法覆盖，以避免单个用户突破整体资源约束。

### 个人配置（普通用户）

当管理员开启「允许用户覆盖以上设置」后，每个用户可在 **插件管理 → 标签页** 页面的「我的偏好」区域调整以下设置，**仅对自己当前浏览器生效**（保存在 `localStorage`，不写入数据库，换浏览器/换设备后需重新设置）：

- 启用标签页模式
- 标签大小
- 标签样式
- 标签最大宽度
- 显示菜单图标
- 显示刷新按钮
- 关闭按钮
- 鼠标中键点击关闭
- 右键菜单
- 刷新后恢复标签

点击「恢复为全局默认」可清除个人覆盖，回退到管理员设置的全局默认值。

### 标签大小对照

| 大小 | 标签高度 | 字号 | 标签间距 | 内边距 |
|------|----------|------|----------|--------|
| 小 | 26px | 12px | 4px | 8px |
| 中 | 32px | 13px | 6px | 10px |
| 大 | 40px | 14px | 8px | 14px |

### 配置存储

- **全局配置**：存储在服务端数据表 `simoTabPageConfig`（单行 JSON `options` 字段），所有用户共享。
- **个人偏好**：存储在浏览器 `localStorage`（键名 `simo-tab-page:prefs`），仅当前浏览器生效。
- **标签列表（刷新恢复）**：存储在浏览器 `sessionStorage`（键名 `simo-tab-page:tabs`），关闭标签页后清除。

### 权限

- 读取全局配置：所有登录用户可读。
- 修改全局配置：需拥有 `pm.tab-page` 权限片段（即插件设置管理权限）。
- 个人偏好：每个登录用户可自行设置，无需特殊权限。
